# Hadal for Inkdrop

Dark theme for Inkdrop 6, based on the VS Code Abyss color theme. It themes the app
UI, Markdown editor and preview as one package.

## Install

Search for **Hadal** in Inkdrop's Plugins view, or install it with the Inkdrop
Plugin Manager:

```sh
npm install -g @inkdropapp/ipm-cli
ipm install hadal
```

Open **Preferences > Themes** and select **Hadal**. Reload Inkdrop if the theme
does not appear immediately.

## Requirements

- Inkdrop 6
- `ipm` only if installing from the command line

## Update and uninstall

```sh
ipm update hadal
ipm uninstall hadal
```
